# Планер BUE 1.9.0

Личный планер. При первом запуске — тема «Боевики 90-х и 2000-х». Выбранное оформление и записи сохраняются локально на устройстве.

Сайт публикуется через GitHub Pages из папки site. Установочные файлы размещаются отдельно в GitHub Releases, версия v1.9.0. Папка packages не входит в репозиторий и публикацию Pages. Лимит каждого release-файла — менее 2 ГиБ.

Для переноса нужен подключённый аккаунт GitHub: создать отдельный публичный репозиторий, загрузить только содержимое этой папки repository, включить Pages с источником GitHub Actions, создать release v1.9.0 и добавить три подготовленных файла из packages. Workflow сам формирует ссылки по фактическому имени репозитория.

На iPhone перед сменой адреса сохраните JSON-копию в настройках старого приложения, затем восстановите её по новому адресу. Записи не переносятся автоматически между доменами. До проверки копии оставьте старый значок.

Ключ Android и персональные записи не входят в этот пакет. iOS ZIP содержит исходники; подписанного IPA нет. Добавлен экспериментальный голосовой ввод: вручную выберите Русский или English, скажите одну команду, проверьте и исправьте запись перед сохранением. Распознавание выполняет Android или браузер; нужен интернет и разрешение микрофона. Реальный микрофон на физических устройствах пока не проверен. Размер текста в настройках — 100–150%, сохраняется на устройстве и работает офлайн.
