# Планер BUE 1.9.1

[Открыть приложение](https://novichoklol-ai.github.io/planer-bue/) · [Android и Windows](https://github.com/novichoklol-ai/planer-bue/releases/tag/v1.9.1)

Дела, календарь с заметками, цели, желания (книги, фильмы, рецепты), финансы и месячный план. При первом запуске — тема «Боевики 90-х и 2000-х»; выбранное оформление сохраняется. Восемь тем, фотографии героев и цветы, закреплённое нижнее меню.

Голосовой ввод: кнопка «Сказать», выбор Русский / English. Например: «Списать 500 рублей на продукты сегодня» или «Add a task buy milk tomorrow». Проверьте команду и сохраните запись. Запись не добавляется автоматически без подтверждения. Нужны интернет, разрешение микрофона и поддержка распознавания на устройстве. На Android используется служба телефона, в веб-версии — браузер. Реальный микрофон на физических устройствах пока не проверен.

Настройки → Размер текста: 100–150%. Выбор сохраняется на устройстве и работает офлайн. Записи и оформление работают без интернета после первой полной загрузки; проверьте надпись «Готов к работе без интернета».

На iPhone откройте сайт в Safari → Поделиться → На экран «Домой». Это веб-приложение; системного виджета и фонового будильника в нём нет. ZIP iOS содержит проект, который ещё не собран и не подписан Apple; установочного IPA нет.

Android: установите APK поверх прежней версии. Windows: распакуйте ZIP и запустите Planer-BUE.exe. Компьютер должен быть включён для напоминаний; выход через значок рядом с часами выключает их.

Перед переходом со старого адреса сохраните JSON-копию в настройках старого планера и восстановите её на новом. Записи между адресами автоматически не переносятся. До проверки копии оставьте старый значок.

Исходники веб-приложения находятся в site; публикация GitHub Pages выполняется через .github/workflows/publish.yml. Установочные файлы и полный пакет около 95 МБ находятся в Releases. Ключ подписи Android, пароли и персональные записи не публикуются.

Проверены команды RU/EN, формы до сохранения, суммы и валюта, недельный план, крупный текст на узком экране, сохранение, офлайн-режим, сборка и подпись APK, правила Windows-напоминаний. Проверка физических телефонов и компиляция native iOS пока не выполнены.

Версия 1.9.1 исправляет зависшее ожидание браузера: готовый результат, пауза и таймер освобождают форму. Максимум записи — 45 секунд; ручная остановка сохраняет текст. Новый единый золотой значок BUE не меняется между темами. На iPhone ранее добавленная иконка может остаться прежней: сохраните резервную копию и добавьте новый значок из Safari; старую установленную версию оставьте до проверки записей.
